# HB_2026: Memory Scrapbook

---

## About

My 'Memory Scrapbook' project is a digital scrapbook for experiences like concerts and adventures, built with plain HTML, CSS, and JavaScript. There are no frameworks or libraries used, just hand-coded. The site organizes photos and videos into custom collections based on different memories with smooth sliding galleries, a custom video player, and a responsive design.

*Note: A separate React version of this project is also in progress.*

---

## Updates

### Completed

- [x] **Getting Started:** Established the project's foundation with self-hosted variable fonts (Unbounded, Big Shoulders Display, and DM Sans) and a base stylesheet using CSS custom properties for colors and typography.
- [x] **Page Structure (1/2):** Semantic HTML layout with a floating glass header, hero headline, and about section.

### Working On

#### Core Site Structures
- [ ] **Page Structure (2/2):** Memory collections section and site footer
- [ ] **Tabbed Interface:** Accessible tabs for switching between memory collections
- [ ] **Media Carousels:** Horizontally scrolling galleries with eased scroll animations that always stop on a fully visible item
- [ ] **Ticket Roll Design:** Connected, perforated gallery segments with a ticket stub opening each collection
- [ ] **Custom Video Player:** HTML5 video with custom controls for play/pause, seeking, mute, and full screen
- [ ] **Hover Captions:** Video captions that appear on hover and hide during playback
- [ ] **Photo Develop Effect:** Photos that fade in like Polaroids using the Intersection Observer API
- [ ] **Full-Screen Viewer:** Smooth photo transitions using the View Transitions API
- [ ] **Responsive Design:** Layouts that adapt to desktop, tablet, and mobile using media queries

#### Future Features
- [ ] **Accessibility:** Keyboard navigation, ARIA labels, visible focus states, and reduced-motion support
- [ ] **Security Hardening:** Safe DOM rendering, no third-party scripts, and a Content Security Policy
- [ ] **Authentication:** Sign in with Google or email
- [ ] **Scrapbook Templates:** Personal scrapbooks created from ready-made layouts
- [ ] **Cloud Uploads:** Photo and video uploads with secure cloud storage
- [ ] **Sharing:** Public scrapbook links with unguessable URLs
- [ ] **Concert Details:** Automatic date, venue, and setlist information from the setlist.fm API
